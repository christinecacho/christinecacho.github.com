# Work Out Log

## Description
A workout tracking app built with FlutterFlow. Record your exercises, track progress, and manage your daily fitness routine easily.

## Features
- Log workouts: exercise name, sets, reps, weight
- View workout history
- Track progress over time
- Simple mobile-friendly design
- Quick data access

## How to Install & Run

### Using FlutterFlow
1. Open your "Work Out Log" project in FlutterFlow
2. Click Preview to test in browser
3. Or use FlutterFlow app to run on mobile

### Using Flutter SDK
```bash
git clone https://github.com/christinecacho/christinecacho.github.io.git
cd christinecacho.github.io
